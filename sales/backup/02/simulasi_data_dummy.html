🧪 Simulasi Data Dummy — Sales Tools Suite

Isi otomatis 5 tabel (users, lead_management, sales_visit_tracker, client_company_profile, sales_pipeline) dengan data dummy yang saling terhubung, supaya semua menu di aplikasi bisa dicoba dengan skenario yang realistis. Semua data yang dibuat di sini ditandai khusus sehingga bisa dihapus total kapan saja dengan satu klik.

👤 -
⚠️ Kamu login sebagai Sales, bukan Supervisor. Generate/hapus data simulasi sebaiknya dilakukan oleh akun Supervisor supaya bisa lihat & kelola semua data (bukan cuma milik sendiri). Kamu tetap bisa lanjut, tapi beberapa tabel mungkin kelihatan kosong karena aplikasi memfilter data berdasarkan sales yang login.

⚙️ Konfigurasi

Endpoint & auth mengikuti persis konfigurasi yang dipakai aplikasi asli — tidak perlu diubah.

API: lidan-co-id.pages.dev/api/contacts_filter_dinamis7 Auth: X-Custom-Auth = admin Marker: 🧪SIM

🚀 Generate Data

Urutannya otomatis: akun simulasi → client → lead → pipeline → kunjungan, supaya nama perusahaan & nama sales konsisten nyambung antar menu.

🗑️ Bersihkan Data Simulasi

Menghapus hanya data bertanda 🧪SIM — data asli/real tidak akan tersentuh. Proses ini menghapus berdasarkan ID yang tercatat di browser ini, plus pemindaian ulang ke server (jaga-jaga kalau kamu generate dari device/browser lain).

📋 Log Proses

Belum ada aktivitas. Klik "Generate" untuk mulai.

📖 Cara Memakai Hasil Simulasi

  1. Klik Generate & Isi Semua Data Simulasi, tunggu sampai log selesai.
  2. Login ulang (logout dulu) memakai akun simulasi yang muncul di kotak kredensial — coba login sebagai Sales untuk lihat tampilan data yang difilter per-sales, lalu coba lagi sebagai Supervisor untuk lihat semua data.
  3. Buka menu Client / Company Profile → lihat daftar perusahaan dummy, coba edit & filter status.
  4. Buka Lead Management → coba ubah status lead (cold → hot → converted), assign ke sales lain.
  5. Buka Sales Pipeline → geser deal antar stage, lihat perhitungan probability & deal value.
  6. Buka Sales Visit Tracker → tandai kunjungan selesai/batal, coba reschedule.
  7. Buka Dashboard → cek apakah rekap angka (jumlah lead, pipeline value, dst) sudah sesuai jumlah data dummy.
  8. Setelah puas belajar, kembali ke halaman ini dan klik Hapus Semua Data Simulasi untuk membersihkan.
