6. ALUR PEMBAYARAN (RINGKASAN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Customer isi form di tes-iq-resmi.html
  2. Klik "Bayar Sekarang"
  3. Data disimpan ke database (status: pending_payment)
  4. HTML fetch ke /api/snap-token (Worker kita)
  5. Worker panggil Midtrans API pakai Server Key
  6. Midtrans return token
  7. Popup Snap Midtrans muncul di browser customer
  8. Customer pilih metode bayar & selesaikan pembayaran
  9. onSuccess / onPending dipanggil → tampil success state
