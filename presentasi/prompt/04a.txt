Bertindaklah sebagai Senior Front-End Developer dan UI/UX Designer Spesialis Web-Based Presentation Deck. 

Tugas Anda adalah membuat satu file HTML mandiri (Single File HTML) utuh yang berisi dek presentasi interaktif premium. Jumlah slide harus dinamis mengikuti jumlah elemen `.slide` yang saya berikan di bagian bawah prompt ini (bisa kurang dari 15, atau bahkan lebih dari 20 slide). Seluruh sistem navigasi, sidebar, progress bar, dan fungsi cetak harus berbasis kalkulasi jumlah slide otomatis (runtime-calculated), bukan angka statis.

Aplikasi harus responsif sempurna baik di layar Landscape (Desktop) maupun Portrait (Mobile Smartphone 420px x 740px) tanpa ada konten yang meluap (No Vertical/Horizontal Overflow).

### ATURAN KODE DINAMIS (WAJIB):
1. CSS Deck Dinamis: Jangan menulis lebar `#deck` dengan angka statis (seperti width: 1500vw). Gunakan Javascript pada fungsi inisialisasi (`init()`) atau saat window resize untuk mengatur lebar `#deck` secara dinamis dengan rumus: `deck.style.width = (slides.length * 100) + 'vw'`.
2. Javascript Navigasi Dinamis: Deteksi total slide menggunakan `const totalSlides = document.querySelectorAll('.slide').length`. Gunakan variabel `totalSlides` ini untuk semua batas logika navigasi `nextSlide()`, pembuatan indikator dots bulat secara otomatis via looping, pengisian daftar menu thumbnail di sidebar, dan penentuan persentase lebar `#progress-bar`.

### STRUKTUR DAN TEKNOLOGI:
1. HTML5 & CSS3 Murni: Gunakan arsitektur flexbox/grid untuk tata letak slide. Tidak boleh menggunakan framework CSS eksternal (Tanpa Tailwind, Tanpa Bootstrap).
2. Google Fonts: Gunakan 'Playfair Display' untuk Heading (h1, h2, h3) dan 'Plus Jakarta Sans' untuk Body Text (p, li, td).
3. Library Eksternal (Ekspor PDF): Wajib sertakan cdnjs untuk html2canvas (1.4.1) dan jspdf (2.5.1) di dalam tag <head> untuk mendukung fitur cetak PDF otomatis sesuai orientasi layar aktif.

### ATURAN UTAMA DESIGN, VISUAL SVG, & RESPONSIVITAS (BEBAS OVERFLOW):
1. Workspace Bound: Bungkus seluruh deck di dalam elemen `#workspace` dengan ukuran dinamis berbasis CSS Variables (`--slide-width` dan `--slide-height`).
2. WAJIB ILUSTRASI/IKON SVG DI SETIAP SLIDE: Setiap slide—tanpa terkecuali, termasuk Slide Pertama (Cover) dan Slide Terakhir (Penutup/Q&A)—wajib memiliki komponen visual berupa inline SVG (bukan link gambar external). 
   - Gunakan grafik SVG yang relevan dengan topik slide (misal: diagram tren, ikon teknologi, ilustrasi abstrak geometris, atau bagan alur).
   - Pastikan SVG menggunakan attribute `viewBox` agar scalable, serta menerapkan warna stroke/fill yang harmonis dengan palette warna (`#14B8A6`, `#6366F1`, `#F59E0B`).
   - Jangan ada slide yang hanya berisi teks kosong.
3. Aturan Portrait Ketat (PENTING): Di dalam `@media (orientation: portrait)` atau kelas `.forced-portrait`:
   - Perkecil padding `.slide` menjadi `40px 24px 90px 24px` agar ruang konten maksimal.
   - Gunakan `flex-direction: column` untuk semua kelas `.two-column`. Bagian visual/grafis SVG wajib ditaruh di atas teks menggunakan `order: -1`.
   - Batasi tinggi elemen visual (`.col-visual` atau SVG) maksimal `12vh` hingga `14vh` agar tidak mendorong konten teks ke bawah.
   - Gunakan tipografi responsif berbasis viewport height (`vh`) untuk teks di mode portrait. Teks deskripsi (`.slide-desc` atau `.card p`) tidak boleh lebih besar dari `18px` (Gunakan kisaran `1.4vh` hingga `1.5vh`) untuk menghindari deteksi teks terlalu dominan atau overflow vertikal di layar 740px.
   - Ubah semua layout grid (`.card-grid` atau `.card-grid-flow`) menjadi satu kolom vertikal tunggal dengan `gap: 8px` dan padding kartu yang dipadatkan (`10px 14px`).
   - Khusus slide berstruktur tabel (seperti roadmap/flow), ubah elemen `table`, `tr`, `td` menjadi `display: block` dengan lebar `100%`.

### FITUR INTERAKTIF DECK:
1. Navigasi Komplit: Tombol panah kiri-kanan (auto-hide di slide ujung), indikator dots bulat di bawah (di-generate otomatis via JS), swipe gesture untuk mobile, dan tombol keyboard (Arrow/Space).
2. Progress Bar: Bar linear tipis di bagian atas layar untuk mendeteksi persentase posisi slide aktif (`(currentSlide / (totalSlides - 1)) * 100`).
3. Top Control Bar: Menu melayang di kanan atas yang memiliki fitur Auto-Hide (hanya muncul saat kursor mendekat/hover) berisi tombol: Toggle Portrait Mode, Fullscreen Mode, dan Slides Menu Sidebar.
4. Sidebar & Ekspor PDF: Menampilkan daftar mini seluruh slide yang bisa diklik untuk lompat langsung ke slide tujuan, serta tombol utama "Ekspor PDF" yang mencetak deck secara presisi menggunakan teknik penundaan render (setTimeout 300ms per slide) agar hasil tangkapan html2canvas jernih dan sempurna tanpa merusak transisi deck.

### PALETTE WARNA & STYLE PREMIUM (DARK MODE):
- Background Utama Deck: `#0F172A` (Navy Deep) dengan kombinasi radial gradient halus.
- Elemen Kartu/Glassmorphism: `rgba(255, 255, 255, 0.03)` dengan border tipis `rgba(255, 255, 255, 0.1)` dan efek backdrop-filter blur.
- Warna Aksen Utama: `#14B8A6` (Teal) untuk teks penting/penekanan (em) dan `#6366F1` (Indigo), `#F59E0B` (Amber) untuk variasi komponen.
- Warna Teks: Utama (`#F1F5F9`), Muted/Keterangan (`#94A3B8`).
