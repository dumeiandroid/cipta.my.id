⏺ Rekam Audio

Untuk merekam audio, ikuti langkah ini:

  1. Klik "Mulai Rekam" di bawah
  2. Browser akan minta izin share tab → pilih tab ini
  3. Centang "Share tab audio" / "Bagikan audio tab"
  4. Klik "Share"
  5. Rekaman mulai otomatis + TTS diputar dari awal
  6. Tunggu selesai → file audio (.webm) otomatis ter-download

Catatan: file .webm bisa diputar di semua media player modern, atau dikonversi ke MP3 via cloudconvert.com.
